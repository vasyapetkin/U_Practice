## МДК 06.02 — Инженерно-техническая поддержка сопровождения информационных систем

### Практическая работа №1 — Настройка удалённого репозитория

Работа с системой контроля версий Git и сервисом GitHub: создание и настройка
удалённого репозитория, систематизация учебных работ, настройка параметров
доступа, проверка доступности репозитория клонированием.

### Лабораторная работа №1 — Восстановление системы (SQLite)

Развёрнуты и проанализированы три программы, использующие СУБД SQLite:
изучены структура баз данных, применяемые SQL-запросы и полнота реализации
операций CRUD. Отдельно проверен приём резервного копирования и восстановления
базы данных.

| Папка | Программа | Описание |
|---|---|---|
| `Программы/1 - Expense Tracker` | Учёт расходов | tkinter + SQLite, операции INSERT и SELECT |
| `Программы/2 - Contact Manager` | Записная книжка | Полный CRUD, ограничения NOT NULL и UNIQUE |
| `Программы/3 - Library Management System` | Учёт книг библиотеки | Полный CRUD, первичный ключ, обработка ошибок целостности |

`backup_demo.py` — сценарий, демонстрирующий резервное копирование базы данных,
имитацию потери данных и восстановление из копии с проверкой целостности.

## Как открыть работы

Отчёты лежат в формате `.docx`, рядом с каждым — копия в `.pdf`
для просмотра без Microsoft Word.

Программы из лабораторной работы запускаются так:

```
cd "МДК 06.02/Лабораторная работа №1 - Восстановление системы (SQLite)/Программы/3 - Library Management System (библиотека)"
python library.py
```

Для программы Expense Tracker дополнительно нужна библиотека:

```
pip install tkcalendar
```

Базы данных `.db` открываются программой DB Browser for SQLite.
